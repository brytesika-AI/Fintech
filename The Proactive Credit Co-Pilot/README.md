# The Proactive Credit Co-Pilot

An AI-driven credit scoring, risk evaluation, and proactive debt restructuring assistant.

## Features
- **Real-Time Credit Risk Scoring:** Computes creditworthiness based on cash-flow velocity, transaction stability, and historical repayment behavior.
- **Proactive Credit Limit Adjustments:** Automatically adjusts borrower credit limits up or down based on continuous financial health monitoring.
- **Early Warning & Debt Restructuring:** Detects potential default signals early and recommends custom repayment restructuring plans.
- **Interactive API Endpoint:** FastAPI service for seamless integration with banking frontends and mobile apps.
